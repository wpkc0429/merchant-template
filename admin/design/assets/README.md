Images, icons and fonts for the design layer. Allowed: svg png jpg jpeg webp gif ico avif woff2 (max 512 KiB each).
Use them from CSS (`url(assets/logo.svg)` in `design/theme.css`) or from a view (`ctx.asset("logo.svg")`).
SVG files must be passive (no script, event handlers, external references). See docs/DESIGN-LAYER.md.
